Random Cat Generator!

For my extension, I turned the original quote generator into a random cat generator that shows both an image of a cat and a fun cat fact. I used two APIs, one for images, and the other for cats.


For my critique project, which explores Amazon's recommendation system, I could imagine using an API that tracks or visualizes how different products are promoted and surfaced to users. For instance, I could use data to compare sponsored items versus organic search results, showing how algorithms often prioritize large sellers over small businesses. An API like that could help reveal biases in product visibility and recommendation systems.
